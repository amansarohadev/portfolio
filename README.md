---

## ✨ Features

- 📊 **Interactive Analytics Case Studies:** Detailed breakdowns of real-world business projects covering context, challenges, SQL queries, DAX measures, and measurable outcomes.
- 📱 **Fully Responsive:** Fluid, clean layout optimized across mobile devices, tablets, and desktop displays.
- 🌓 **Theme Toggling:** Built-in Light and Dark mode with smooth ambient gradient transitions.
- ⚡ **High Performance:** Built with React 19, TypeScript, and Vite for instant load times and snappy navigation.
- 💼 **Recruiter-Ready:** Direct access to project repositories, AZ-104 certification proof, and 1-click contact channels.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites
Make sure [Node.js](https://nodejs.org/) (v18+) is installed.

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/amansarohadev/portfolio.git
```

2. **Navigate into the project directory:**
```bash
cd portfolio
```

3. **Install dependencies:**
```bash
npm install
```

4. **Start the local development server:**
```bash
npm run dev
```

> The application will be live at `http://localhost:5173`.
